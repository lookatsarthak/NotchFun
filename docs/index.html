      Installing

      Is the Terminal line safe to paste?

      Be careful with any website that asks you to paste a command, this one included. This line fetches one script from NotchFun's GitHub repository. It checks your macOS version, downloads the latest release, copies it to Applications, opens it and sends one anonymous install count. It needs no password. Read every line first if you'd like to.

      Terminal may show Paste Blocked, a macOS warning about commands copied from websites. Choose Paste Anyway if you're happy with this one, or use the download instead.

      Why does macOS stop the app the first time I open it?

      Apple only skips that step for apps notarised through its Developer Program, which costs US$99 a year. NotchFun is a free side project, so it isn't notarised. It isn't a finding about the app.

      It happens once. Click Done, not Move to Trash, then open System Settings → Privacy & Security, click Open Anyway and confirm. The Terminal line skips this step: it downloads with curl, which macOS doesn't mark for checking, and clears any mark that's there.

      What if the Terminal line doesn't work?

      Read the last line Terminal printed. If the download failed, run the line again. If it says your macOS is too old, see the next question. If it still won't go, use the download above, or report it and paste what Terminal printed. Homebrew works too: brew install --cask lookatsarthak/tap/notchfun

      Which Macs does it run on?

      Any Mac on macOS 26 Tahoe or later. No notch? NotchFun draws one at the top of the screen, and you can set its height in Settings. On macOS 15 Sequoia, NotchFun 1.2.1 still works.

      Using it

      Is it really free?

      Yes. No trial, no account, no in-app purchases. It's open source under the GPLv3.

      What permissions does it need?

      Only what the features you turn on need: Calendar and Reminders for events, Camera for the mirror, Accessibility for pasting and the volume popup. Setup asks at the moment it matters.

      Does anything leave my Mac?

      The app has no accounts and no analytics. It checks GitHub for updates, and if you turn on lyrics it looks up the current song on LRCLIB. Your clipboard never leaves your Mac. This website and the installer keep anonymous counts of visits, clicks and installs — no cookies, nothing that identifies you.

      How do I uninstall it?

      Open Settings → General and click Quit app, then move NotchFun from Applications to the Trash. If you installed with Homebrew, run brew uninstall --cask notchfun.
